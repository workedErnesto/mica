# mica для Windows

Windows-версия написана в `windows/` и собирается в CI на `windows-latest`. Компилятор проверил весь код на Mac против настоящих сборок WinUI 3 и WebView2. На живой Windows приложение ещё не запускалось, поэтому в [PARITY.md](PARITY.md) у каждой функции Windows стоит статус «написано, не запускалось», пока его не проверят руками.

## Стек

C# на .NET 10, WinUI 3 (Windows App SDK 2.6), Microsoft Edge WebView2, публикация Native AOT. С 11 ноября 2026 года интерфейс окна нарисован не элементами XAML, а оболочкой mica в `windows/shell`: HTML, CSS и JavaScript без сторонних библиотек, которые повторяют SwiftUI-виды macOS по геометрии, цветам и движению. Прежний интерфейс на XAML владелец отклонил: анимации там были сдвигами Composition и выглядели иначе, чем на Mac.

Окно WinUI держит два слоя над акриловым фоном:

1. Оболочка (`Shell/ShellView.cs`) в собственном WebView2 с прозрачным фоном. Файлы читаются из папки приложения через виртуальный хост `https://mica.shell`, значки сайтов и иконки приложения отдаёт сама mica по адресу `https://mica.icons`. Оболочка не ходит в сеть.
2. Страница выбранной вкладки в своём WebView2. Оболочка оставляет в карточке «окно» и после каждой отрисовки сообщает его прямоугольник, а во время анимации раскладки сообщает его каждый кадр. Окно ставит страницу туда и скругляет её углы радиусом карточки. Когда оболочка рисует поверх страницы (меню, командная строка, карточки уровня окна), её слой поднимается над страницей.

Состояние окна живёт в C# (`BrowserModel`, `Tab`, `Store`). Оболочка получает его снимком JSON (`Shell/ShellState.cs`) и отправляет команды обратно (`Shell/ShellCommands.cs`). Пружины macOS (`response`, `dampingFraction` из `shared/tokens.json`) переводятся в CSS `linear()` по точному решению затухающего осциллятора, поэтому кривые совпадают с SwiftUI (`shell/js/core/motion.js`). Переходы появления и удаления, переезд элементов (FLIP) и сборка знака mica по буквам повторяют модификаторы SwiftUI. «Эффекты анимации» Windows выключены: движения нет, остаются переходы прозрачности и цвета.

Оболочку можно открыть без Windows: `windows/shell/dev/mock-host.js` подменяет хост тестовыми данными, когда страница открыта вне WebView2. Этим пользуется предпросмотр в боковом браузере ассистента; в сборку приложения папка `dev` не попадает.

WebView2 — системный движок Windows на основе Chromium, он обновляется вместе с Edge. Так он играет ту же роль, что WKWebView на macOS. Отличия движков разобраны в [PARITY.md](PARITY.md).

## Структура

```
windows/
  mica.sln
  Directory.Build.props   общие свойства, версия из shared/version.txt
  Dotnet.props            net10.0, на машине только с SDK 8 откат на net8.0
  WinUI.props             Windows App SDK и WebView2; вне Windows только ссылки для компиляции
  src/
    Mica.Core/            модели без UI: порт MicaCore, общие тестовые векторы, строки и клавиши из shared/
    Mica.Design/          токены (Palette.g.cs и др. генерируются), пружины Composition, кнопки, переключатели,
                          сегменты, поля, группы настроек, меню, модальная карточка
    Mica.Install/         установка без прав администратора: раскладка, реестр, ярлыки, WebView2 Runtime, распаковка
    Mica.App/             браузер: окно и слои WebView2, модели окна и вкладок, мост к оболочке, загрузки, пароли, удаление
    Mica.Setup/           установщик mica Setup в том же дизайне, один exe с встроенным приложением
  shell/                  интерфейс окна: index.html, css/ (tokens.g.css из shared/), js/core (рендер, пружины, иконки, мост),
                          js/ui (контролы, меню, перетаскивание), js/shell (шапка, вкладки, начальная страница, панели, настройки)
  tests/Mica.Core.Tests/  xUnit, запускается и на Mac
  scripts/                build.ps1, install.ps1, smoke.ps1, setup-click.ps1
```

Общие данные в `shared/`: токены дизайна, английские строки, раскладка клавиш, соответствие глифов, иконки (ICO и PNG из HEIC), список блокировки, тестовые векторы, версия. `scripts/generate.py` пишет из них Swift и C#, а `scripts/check-parity.py` проверяет, что платформы не разошлись.

## Сборка

На Windows с .NET 10 SDK и Python 3:

```powershell
windows/scripts/build.ps1            # тесты, приложение Native AOT, установщик
windows/scripts/install.ps1          # то же и тихая установка для текущего пользователя
windows/scripts/smoke.ps1            # smoke-тест с отдельным QA-профилем
```

Результат: `windows/artifacts/mica-<версия>-win-<x64|arm64>-setup.exe` и `.sha256` рядом с ним.

На Mac проверяется ядро и компиляция всего Windows-кода:

```bash
cd windows && dotnet test tests/Mica.Core.Tests && dotnet build mica.sln
```

CI (`.github/workflows/windows.yml`) выполняет проверку паритета, тесты, сборку x64 и arm64. Для каждой архитектуры он проверяет запуск установщика (`--self-test`), установку настоящими кликами мыши по кнопкам «Параметры», «Назад», «Установить» и «Закрыть» (`setup-click.ps1`, скриншоты каждого шага выкладываются артефактом), тихую установку и smoke-тест с настоящим WebView2. Отчёты и установщики выкладываются артефактами CI; после успешной проверки установщики прикрепляются к релизу вручную.

## Установщик

`mica-setup.exe` — одно окно в дизайне mica на Mica или Acrylic. Порядок такой:

1. Знакомство: иконка с пружиной, кнопки «установить» и «параметры».
2. Параметры, отдельным экраном: папка, ярлык на рабочем столе, браузер по умолчанию, кнопки «установить» и «назад».
3. Прогресс: настоящий процент распаковки.
4. Готово: кнопки «открыть mica» и «закрыть».

Установка идёт для текущего пользователя в `%LOCALAPPDATA%\Programs\mica`, права администратора не нужны. Установщик регистрирует mica как браузер (HKCU), создаёт ярлык в «Пуске» и запись в «Установленных приложениях». Распаковка идёт в соседнюю папку и подменяет старую только целиком, поэтому прерванная установка оставляет прежнюю версию рабочей.

Если WebView2 Runtime нет, установщик с согласия пользователя скачивает и запускает его установщик от Microsoft. Режим `--update` дожидается выхода mica, ставит новую версию и запускает её. `--quiet` ставит с параметрами по умолчанию.

Удаление выполняет сама mica (`mica.exe --uninstall`). Она спрашивает, оставить ли данные профиля, затем снимает регистрацию, ярлыки и запись и удаляет папку после выхода.

Сборка не подписана Authenticode, поэтому SmartScreen покажет «неизвестный издатель». Подпись требует платного сертификата, и решение о нём ещё не принято.

## Что проверить дома первым

1. Установщик: запуск, тихая установка без прав администратора, ярлык в «Пуске», запись в «Установленных приложениях», удаление с вопросом о данных.
2. Стекло на оболочке и непрозрачная карточка, светлая и тёмная тема, кастомный акцент, выключенные «Эффекты прозрачности».
3. Шапка: перетаскивание окна за пустые места, Snap Layouts на кнопке «развернуть», двойной клик, клики по кнопкам и адресу.
4. Горячие клавиши, когда фокус внутри страницы: Ctrl+T, Ctrl+L, Ctrl+W, Ctrl+Tab, F5, Ctrl+F. WebView2 должен отдавать их окну при выключенных `AreBrowserAcceleratorKeysEnabled`. Это главный риск вслепую.
5. Вкладки: открытие, закрытие, перестановка перетаскиванием, анимации, боковая и верхняя раскладки, колонка иконок, «Эффекты анимации» выключены.
6. Слои: страница стоит ровно в карточке и не отстаёт во время анимации сворачивания панели и открытия библиотеки; углы страницы скруглены; меню и командная строка видны поверх страницы; клики по пустой шапке двигают окно, Snap Layouts на кнопке «развернуть» работает.
7. Видео в фоновой вкладке играет дальше, вкладка не перезагружается при возврате.
8. Инкогнито не делит cookie с обычным окном и с другим окном инкогнито.
9. Загрузка: диалог сохранения, пауза, возобновление, «показать в проводнике».
10. Камера, микрофон, геолокация и уведомления на тестовых сайтах; клик по уведомлению выбирает вкладку.
11. Импорт из других браузеров, в том числе при открытом исходном браузере.
12. Сохранение и заполнение пароля, Windows Hello при показе.
13. Ссылка из другой программы после выбора mica браузером по умолчанию.
14. Масштаб интерфейса 150%, второй монитор, ширина окна меньше 760 px.
15. Память в диспетчере задач на 10 вкладках (`--qa --benchmark=10` пишет `benchmark-10.tsv`).
