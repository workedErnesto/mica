# Паритет macOS и Windows

Статусы: «проверено» значит, что функцию прогнали в настоящем приложении; «написано» значит, что код есть и компилируется, но в живом приложении не запускался; «нет» значит, что функции нет, причина указана. Windows-версия целиком в статусе «написано», пока её не проверят на Windows (чек-лист в [WINDOWS.md](WINDOWS.md#что-проверить-дома-первым)).

Автоматически сверяются: поведение ядра (общие векторы в обоих наборах тестов), токены дизайна, английские строки, глифы, клавиши и версия (`scripts/check-parity.py`, CI).
