# mica: архитектура и модель приватности

## Платформа

Минимальная версия — macOS 15.4. Выбор связан с публичными `WKWebExtensionController`, `WKWebExtensionContext`, `WKWebExtensionTab` и `WKWebExtensionWindow`, доступными начиная с 15.4. Проверка сделана по заголовкам SDK Xcode 26.1 и [документации Apple](https://developer.apple.com/documentation/webkit/wkwebextensioncontroller). Ранние версии macOS не предлагаются как поддерживаемые.

AppKit управляет жизненным циклом приложения, настоящими окнами, responder chain, меню, системными диалогами и печатью. SwiftUI отображает оболочку, настройки, онбординг и панели. Содержимое сайтов исполняет системный WebKit в его процессах. Приложение не отключает изоляцию процессов и не использует private API. Исправления движка приходят через обновления macOS.

Правило зависимостей: MicaCore не знает о MicaApp, AppKit и WebKit; всё, что можно проверить без окна, живёт там и покрыто тестами. Внутри MicaApp папки соответствуют возможностям браузера; DesignSystem не зависит от остальных папок, кроме Store для текста. Один файл содержит один экран или один компонент с его приватными частями.

## Вкладки и владение

Store удерживает контроллеры окон. Контроллер удерживает BrowserModel, модель — вкладки, вкладка — свой WKWebView и KVO-наблюдения. Обратные ссылки вкладка → окно и модель → контроллер слабые. При закрытии сбрасываются наблюдения, делегаты, загрузка и захват устройств, представление удаляется из иерархии.

В иерархии AppKit находится WKWebView выбранной вкладки. Остальные загруженные WKWebView продолжают существовать. Смена вкладки не создаёт новый web view, не выполняет reload, не подменяет JavaScript сайта и не вызывает pauseAllMediaPlayback. Фоновую активность и видимость обрабатывает WebKit. Автоматическое воспроизведение аудио и видео требует действия пользователя через публичную конфигурацию WebKit; активное воспроизведение не останавливается при переключении вкладки. Это не обещание, что ОС никогда не завершит процесс под давлением памяти.

Состояния различаются явно: новая вкладка, сохранённая и ещё не загруженная после запуска, живая, завершённая системой. Нет режима автоматической выгрузки и периодического таймера. Ручная выгрузка живых вкладок также не предлагается: публичного достоверного детектора всех форм, WebSocket и фоновых звонков нет.

## Сессия

JSON хранит только HTTP/HTTPS-адреса, оригинальные заголовки, идентификаторы, закрепление, порядок и выбор по окнам. Приватные окна в снимок не попадают. Запись сессии отложена на 400 мс после изменений и выполняется атомарно; перед нормальным завершением выполняется принудительная запись. Не сохраняются DOM, несохранённые формы, вкладочная back-forward history и живые сетевые соединения. После сбоя возможно потерять последние изменения до отложенной записи.

Ленивая загрузка применяется только к сохранённым вкладкам после запуска. Выбранная вкладка загружается сразу; для остальных действует настройка и список доменов, которые загружаются всегда. При завершении web content process показывается ошибка и явное восстановление. mica не маскирует потерю состояния автоматическим reload.

При ошибке чтения настроек/истории/закладок или сессии приложение сохраняет копию исходного файла в `Recovery` и показывает ошибку. JSON неизвестной версии сессии не интерпретируется как актуальный формат. Небезопасные URL и повторяющиеся идентификаторы при восстановлении отбрасываются.

## Данные

Обычные окна используют WKWebsiteDataStore.default и общий профиль. Каждое приватное окно создаёт собственный `.nonPersistent()` data store; вкладки этого окна разделяют его, новые приватные окна не разделяют. История, закрытые приватные вкладки и решения приватного окна существуют только в его модели и уничтожаются при закрытии окна. Расширения не подключаются к приватным web views и не получают приватные окна через делегат.

Профиль JSON находится в sandbox-контейнере `app.mica.browser`, под `Data/Library/Application Support/mica`. Права JSON-файлов — 0600. Данные сайтов управляются WebKit. Это не собственное шифрование диска: защита устройства и FileVault остаются ответственностью macOS. Приложение не сохраняет введённые пароли. HTTP Basic-auth использует credential без постоянного сохранения. Адреса со встроенными credentials не принимаются и не восстанавливаются. Собственный password manager или Keychain-хранилище секретов не добавлены.

История ограничена 3000 посещениями. Закладки могут сохраняться явным действием пользователя и из приватного окна; это постоянные пользовательские данные, в отличие от автоматической истории приватного окна. Скачанные файлы, выбранные для сохранения в приватном окне, также остаются на диске.

Диагностический `--qa` использует отдельный путь JSON, отдельный идентификатор постоянного WKWebsiteDataStore и отдельную конфигурацию WKWebExtensionController. Тестовый профиль не является приватным окном.

## Разрешения и безопасность

Камера и микрофон проходят через публичный `WKUIDelegate.requestMediaCapturePermissionFor`. Проверяются HTTPS и совпадение запрашивающего origin с `WKFrameInfo.securityOrigin`; request URL фрейма не используется как подмена происхождения. Новые запросы невыбранной вкладки отклоняются. Запрос называет сайт, возможность и встроенный фрейм, если он есть. Пользователь выбирает отказ, один запрос или сохранённое решение сайта. Дополнительно проверяется системный доступ AVFoundation; системный запрет не обходится.

Разрешения нормального профиля можно изменить в настройках или сведениях сайта. Отзыв разрешения останавливает текущий захват соответствующей возможности. Кнопка остановки в сведениях сайта останавливает обе дорожки. Иконка захвата дополняет системные индикаторы, а не заменяет их.

В SDK для целевой версии нет пригодного публичного делегата управления геолокацией WKWebView по сайтам или провайдера web push уведомлений. mica показывает этот статус текстом. Геолокация не замещается собственным JS-мостом, push не симулируется локальными уведомлениями. Информацию о будущих beta API нельзя считать доступностью на проверенной ОС.

TLS проверяет система. Универсального обхода ошибок сертификата нет. Разрешение ATS относится только к web content для обычных HTTP-сайтов; сетевые запросы самого приложения остаются HTTPS. HTTP показан как неподтверждённое защищённое соединение. HTTPS-индикатор требует `serverTrust`, HTTPS URL и `hasOnlySecureContent`; он не является оценкой добросовестности сайта.

Только `http`, `https`, системный `about:blank` и ограничиваемые WebKit blob URL проходят навигацию. `mailto` и `tel` требуют явного подтверждения открытия другого приложения. Ввод `javascript:`, `data:` и `file:` в адресную строку не выполняется. Стандартные контекстное меню WebKit, редактирование, clipboard, поиск, масштаб и печать сохранены.

## Загрузки

WKNavigationAction/Response переводятся в `.download`, затем используется WKDownload. Место выбирается NSSavePanel, загрузка сначала идёт во временный файл внутри контейнера, затем переносится к выбранному назначению. Существующий файл не заменяется без подтверждения. Записываются системные quarantine properties; `LSFileQuarantineEnabled` включён. Автоматического открытия нет. Открытие результата требует действия и подтверждения пользователя, проверку исполняемых файлов продолжает macOS.

Прогресс приходит от `Progress`, без опроса таймером. Отмена и ошибки отделены от успешного сохранения. Возобновление показывается только при наличии resumeData от WebKit, иначе доступен новый запрос. Это не гарантия возобновления для любого сервера, POST или истёкшего blob URL. При закрытии окна с активными загрузками есть предупреждение. Выбор файлов для сайта выполняется NSOpenPanel, включая множественный выбор и папки, когда этого требует сайт.

## Сеть и entitlements

Release entitlements: App Sandbox, исходящие соединения, выбранные пользователем файлы read-write, камера и audio input. Нет доступа ко всему диску, automation/Apple Events, network server, отключения library validation или частных браузерных привилегий. В debug добавляется только `get-task-allow` для измерений.

Собственной аналитики и SDK телеметрии нет. Сеть используется сайтами, поисковиком при отправке запроса, AMO при поиске каталога и `pgl.yoyo.org` при ручном обновлении списка. Расширения могут выполнять свои сетевые запросы после включения; их права и политика источника важны. Установщик приложения не содержит автообновления бинарника. Системная сеть macOS этим описанием не ограничивается.

## User-Agent

WKWebView по умолчанию не добавляет токен `Version/... Safari/...`, и часть сайтов считает такой клиент неизвестным ботом (Яндекс показывал капчу на первый же запрос). mica работает на системном WebKit того же Safari, поэтому через публичный `applicationNameForUserAgent` добавляет `Version/<версия установленного Safari> Safari/605.1.15`. Версия читается из Info.plist Safari, запасное значение 18.0. Других изменений идентификации нет.

## Поисковики

DuckDuckGo, Google, Яндекс (`https://yandex.ru/search/?text=`), Kagi и Bing. Запрос уходит только выбранному поисковику. Неизвестное значение в сохранённых настройках заменяется DuckDuckGo без потери остальных настроек.
